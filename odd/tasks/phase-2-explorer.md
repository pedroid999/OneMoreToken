- L10 (T2 design, parent decision):
  - **Read-only without locks.** Opening the live WAL database (even `readOnly`) takes read marks in `-shm`; `immutable=1` ignores the WAL. The reader copies `opencode.db` and `opencode.db-wal` (never `-shm`) into a private `mkdtemp` directory (`copyFile` with `COPYFILE_FICLONE`), opens the copy with `node:sqlite`, and removes the directory in `finally`. If db/wal size or mtime changed during the copy, retry once, then report a failure. Source files are never opened for writing.
  - **SQLite wins.** Legacy `storage/` sessions are ingested only when their id is absent from the database (or the database is missing).
  - **One source per session.** Virtual absolute path `<opencode data dir>/sessions/<sessionId>` for both origins, so a child's `parent_session_id = recordId(sourceFileId("opencode", join(dirname(context.path), parentId)), "session", parentId)`.
  - **Content never leaves the reader.** The reader projects each session into a canonical metrics-only JSON document (stable key order and sort by time then id); its hash drives incremental skip through the existing `ingestSource`. Message projection keeps only role, modelID, providerID, cost, tokens, variant, mode, summary, time; parts keep only `tool` (callID, tool, status, start, end) and `compaction` (type). Unreadable message/part files become null entries → `invalid_json` issues with a numeric location.
  - **Mapping.** One turn per user/assistant message (role = message role; model/provider/effort from assistant modelID/providerID/variant, null for user). Usage only from assistant `tokens`: output = output + reasoning; cache read/write; reported cost = `cost`; computed via `calculateCost`. Missing tokens → `missing_usage`. `is_compaction` = message has a compaction part. Tool calls from completed (ok) / error (error) parts; `running` skipped. Session: cwd = directory, started/ended = created/updated, `format_version` = `opencode-<origin>/<version|unknown>`. `since` filters by session updated time. `mode`/`agent` role is not stored yet (no column; Phase 3).
  - Default root `${XDG_DATA_HOME:-~/.local/share}/opencode`; `--agent opencode --path <data dir>` supported; symlinked db/storage skipped as for other roots.
